# Производительность

## Методология

Измерения выполнялись на production-сборке, запущенной через `vite preview`; базовые замеры — на `http://localhost:4173/`, финальные после переноса UI kit — на `http://localhost:4174/`. Lighthouse 12.8.2 запускался с мобильным профилем, `--screenEmulation.mobile` и `--throttling-method=simulate`. После основной аудиты для `/` сделано 4 прогона из-за разброса первого результата; в отчёт взят медианный прогон (Performance 96, LCP 2.3 s).

**Полевые данные CrUX/RUM недоступны.** Поэтому LCP/CLS ниже — лабораторные метрики, а INP напрямую не измерен; TBT использован только как лабораторный прокси.

В ходе переноса UI kit системный Chrome обновился с 157 до 158, и Lighthouse начал запускать обычный `Chrome/158` вместо headless-браузера. Повторные замеры в этом режиме дали несравнимо низкие оценки (Performance 87–88, LCP 3.3–3.4 s, TBT 30–70 ms) как до, так и после восстановления разделения JS-чанков, то есть разница обусловлена средой измерения, а не кодом сайта. Для сопоставимости с baseline финальные замеры выполнены через `chrome-headless-shell` 154 с тем же мобильным профилем; по `/` сделано 3 прогона (Performance 95, 95, 94), в артефакт взят медианный.

SEO вырос до 100 после добавления `robots.txt`, валидной `sitemap.xml`, `canonical`, OG и robots meta. Accessibility `/about` вырос до 100 после замены низкоконтрастного акцентного текста.

Небольшое изменение CLS на `/` (0.04 → 0.07) остаётся в пределах цели ≤ 0.1; хеши Header, анимации, hero-текст и геометрия капсулы после переноса UI kit совпадают с эталоном. Оценки Lighthouse лабораторные и зависят от версии браузера, поэтому сравнивать их нужно только в одинаковом headless-режиме.

Цели: LCP ≤ 2.5 s, CLS ≤ 0.1, INP ≤ 200 ms. Лабораторные LCP и CLS укладываются в цели. Подтверждения полевого INP нет.

## Размеры ресурсов

| Показатель | До | После аудита | После UI kit |
| --- | ---: | ---: | ---: |
| Сумма чанков `dist/assets/*.js` | 1 016 777 B | 885 060 B | 886 110 B |
| Чанк Lottie | 306 347 B | 169 111 B | 169 111 B |
| CSS | 41 080 B | ~41 130 B | 40 229 B |
| Шрифты `.woff2` | 5 файлов | 5 файлов | 5 файлов |

Уменьшение JS достигнуто заменой импорта `lottie-web` на `lottie-web/build/player/lottie_light`: анимация использует только SVG-рендерер. `prefers-reduced-motion` и жизненный цикл mount/unmount анимации не менялись. Контроль DOM анимации до/после дал одинаковый хеш и длину SVG-содержимого, поэтому визуал Hero сохранён.

После переноса CSS собирается отдельным entry `ui-kit/vite.styles.config.ts`: шрифты Geist остаются внешними `.woff2` с относительными URL, `data:font` в `styles.css` отсутствует. Рост JS на 1 050 B вызван дополнительной логикой импорта пакета; в сопоставимом headless-режиме он не привёл к значимой просадке Lighthouse-оценок.

## Дополнительные проверки

- Сборка с `VITE_BASE_PATH=/website` создаёт ссылки `/website/assets/...`, а `404.html` использует тот же base.
- `robots.txt` и `sitemap.xml` попадают в `dist`.
- Lighthouse не показывает неуспешных SEO/accessibility/best-practice аудитов после изменений.
- E2E-тест `frontend/e2e/home-baseline.spec.ts` сравнивает 5 состояний Home/Header с `baseline-home.json`, поэтому визуальная регрессия при переносе UI kit была бы сразу обнаружена.
- Прямые обращения к демо GitHub Pages проверялись только до изменений; публикация не выполнялась.
